## How to Run the Projects

1. Clone the repository.

```bash
git clone https://github.com/Layana7592/R-Data-Analysis.git
```

2. Open the project in RStudio.

3. Install required packages.

```r
install.packages(c(
  "ggplot2",
  "dplyr",
  "corrplot",
  "rmarkdown"
))
```

4. Run any analysis script.

```r
source("scripts/descriptive_statistics.R")
```

5. Open `.Rmd` files and click **Knit** to generate HTML reports.
